# Changelog

## 0.3.0 — 2026-10-15

- Redesign the interface with ship search, clearer panels, and improved scrolling.
- Edit original ships’ building ports and industry requirements.
- Import custom PNG portraits with a converter and preview.
- Add optional Repair Safeguard.
- Add Fleet Control (Experimental), with manual mate turns, camera focus, and a Select automation toggle.

## 0.2.0 — 2026-10-14

- Add up to five new ship classes while keeping all 25 originals.

- Choose ports, industry requirements, and original ship graphics for new ships.

- Edit total capacity and starting equipment for added ships; cargo is calculated automatically.

- Improve the layout and add independent scrolling for ship lists and settings.

- Open projects saved in v0.1.0.

## 0.1.0 — 2026-10-14

- Initial release for the original USA game.

- Edit the 25 original ships’ names, stats, and base prices.

- Display prices in gold bars.

- Save and load projects.

- Export a modified ROM and IPS patch.
