# Changelog

## 1.0.1 — October 18, 2026

- Keep item and goods shuffle buttons visible in smaller windows.

## 1.0.0 — October 16, 2026

- Add seeded and blind ship-building randomization for the original 25 ships, with a standalone preset and combined preset support.

- Revamp Easy Settings with 13 combinable presets, change previews, seeds and blind mode.

- Rename the Gameplay World shuffle setting to Use random goods.

- Organize Help into Getting Started, Features & Settings, Compatibility & Troubleshooting, and About.

- Organize Gameplay into Easy Settings, Battles and World; show fleet, mate and item arrangement categories together on the World page.

- Add item shop editing and seeded item shuffles with three scopes and blind mode.
- Add Easy Settings presets and a manual editing lock for ships.
- Move World editing checkboxes above the map and details.

- Add Economy editing for individual ports and regional batches, with previews and live Port Information updates.

- Edit goods selling ports and economy requirements; show the results in read-only Port Information.

- Fix character resets and list arrow-key navigation; default Repair Safeguard to Off.

- Add section resets and bright orange markers for changed values, list entries and sections.

- Tighten ship layouts and clean up card edges.
- Apply valid field edits automatically and summarize active changes in Gameplay.

- Fit port details across wide windows and keep the map steady between World views.
- Correct specialty text and early-shop time labels.

- Fix scrolling over empty areas in World so lower lists remain reachable.

- Browse shop items with original pictures, descriptions, selling ports and offer hours.

- Show each port’s goods and ship unlock requirements with starting-value dividers.

- Add a Goods browser with selling ports on the map and tighten the World layout.

- Browse discovery locations in World.

- Give Gameplay its own section and add a World port browser with a ROM-derived map.

- Add Custom Fleets (Experimental) with nation-specific flagship and escort choices.

- Add searchable Mates and Fleet Captains lists with portraits, nationality, and editable attributes and skills.
- Add a shareable four-digit seeded free-agent starting-port shuffle with an optional blind mode.

## 0.3.0 — 2026-10-15

- Improve the layout and add independent scrolling for ship lists and settings.

- Open projects saved in v0.1.0.

## 0.1.0 — 2026-10-14

- Initial release for the original USA game.

- Edit the 25 original ships’ names, stats, and base prices.

- Display prices in gold bars.

- Save and load projects.

- Export a modified ROM and IPS patch.


Random mate starting-port changes highlight Mates and affected mate entries, including blind shuffles. Gameplay highlighting reflects battle and custom fleet settings.

- Added Trade goods shuffles and optional mate/captain name and stat shuffles, using four-digit seeds. Shuffled stats range from 50–100.

- Name shuffles now mix first and last names independently.

- Stat shuffles now preserve each character’s original total, with every stat between 50 and 100.

- Added seeded mate and captain skill shuffles, keeping each character’s original skill count.

- Condensed Gameplay World text and added a responsive two-column layout.

- Changed Gameplay World to inline checkbox settings with seed and scope controls.

- Restored configuration/preview popups for every World shuffle. Mate preview now lists actual before/after changes.

- Organized mates, fleet captains, items and cargo randomizers into separate checkboxes and configuration popups.

- Removed duplicate Configure buttons; active seed links reopen randomizer settings.
