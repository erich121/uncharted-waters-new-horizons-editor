
New Horizons Editor Changelog

1.1.0 - October 21, 2026

ADDED
- Add a Content Library for creating, saving, organizing and sharing custom ships, discoveries and items.
- Add Library collections with import and export support.
- Include 35 custom ship designs with original artwork, specifications and descriptions.
- Expand the ship roster from 5 to 10 additional classes, allowing 35 ship classes per ROM.
- Add 98 custom discoveries with original artwork, names and historical descriptions.
- Add discovery editing with custom artwork, descriptions, categories and difficulty settings.
- Add AI assisted game creation with custom preset generation and importing.
- Add complete game presets with support for saving and loading entire configurations.
- Add project sharing with embedded custom ships, discoveries, artwork and gameplay settings.
- Add editing for all six playable characters, including starting attributes, levels, skills and Luck.
- Add custom shipyard descriptions and expanded ship customization.
- Add Campaign settings for starting gold, a 50-year deadline and instant shipbuilding.
- Add a protected Original Game preset for restoring the original configuration.
- Add the ability to save individual creations from shared projects into the Content Library.
- Add support for preserving replaced custom ships in the Content Library.

IMPROVED
- Improve ship layouts, World information, input scrolling and change indicators.
- Improve shipyard management and custom ship availability settings.
- Improve discovery browsing, artwork previews and replacement management.
- Improve character editing and starting attribute customization.
- Improve preset management and configuration previews.
- Improve interface scaling and compatibility with smaller displays.
- Improve project saving, backups and recovery.
- Improve export validation and overwrite protection.
- Improve configuration validation and error handling.
- Strengthen project, preset and Library saving, backups, export validation and recovery.

CHANGED
- Replace the original 13 combinable presets with complete game configurations.
- Reorganize preset management and integrate AI preset importing.
- Separate personal Library content from saved project configurations.
- Organize original Library content into Stock Ships and Stock Discoveries collections.
- Integrate existing seeded randomizers into the new preset system.
- Preserve custom Library content when loading different presets.

FIXED
- Fix custom discovery artwork transparency.
- Fix item and trade goods shuffle controls on smaller displays.
- Fix additional interface scrolling and layout issues.
- Improve file handling to prevent accidental data loss.
- Improve validation of imported configurations and custom content.

- Add Easy Settings presets and a manual editing lock for ships.

- Add Economy editing for individual ports and regional batches, with previews and live Port Information updates.
- Edit goods selling ports and economy requirements; show the results in read-only Port Information.
- Fix character resets and list arrow-key navigation; default Repair Safeguard to Off.
- Add section resets and bright orange markers for changed values, list entries and sections.
- Tighten ship layouts and clean up card edges.
- Apply valid field edits automatically and summarize active changes in Gameplay.
- Fit port details across wide windows and keep the map steady between World views.
- Correct specialty text and early-shop time labels.
- Fix scrolling over empty areas in World so lower lists remain reachable.
- Browse shop items with original pictures, descriptions, selling ports and offer hours.
- Show each port's goods and ship unlock requirements with starting-value dividers.
- Add a Goods browser with selling ports on the map and tighten the World layout.
- Browse discovery locations in World.
- Give Gameplay its own section and add a World port browser with a ROM-derived map.
- Add Custom Fleets with nation-specific flagship and escort choices.
- Add searchable Mates and Fleet Captains lists with portraits, nationality, and editable attributes and skills.
- Add a shareable four-digit seeded free-agent starting-port shuffle with an optional blind mode.
